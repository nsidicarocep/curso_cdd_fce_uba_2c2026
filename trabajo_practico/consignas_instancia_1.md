# Trabajo Práctico de Ciencia de Datos

## Primera entrega: Análisis Exploratorio de Datos

### Objetivo

El objetivo de esta primera entrega es realizar un **Análisis Exploratorio de Datos (EDA)** sobre la base seleccionada para el Trabajo Práctico.

Esta primera etapa busca que los grupos:

* conozcan y comprendan la base de datos;
* identifiquen sus principales características;
* describan las variables disponibles;
* comiencen a explorar los datos mediante tablas, estadísticas y gráficos sencillos;
* desarrollen una primera interpretación de los resultados;
* comiencen a trabajar en la presentación de información y resultados.

Las siguientes entregas permitirán profundizar el análisis y mejorar progresivamente la presentación de los resultados.

---

## 1. Presentación de la base de datos

Realizar una breve presentación de la base utilizada.

Se deberá indicar:

* **Nombre de la base de datos.**
* **Fuente.**
* **¿Qué fenómeno o población representa?**
* **¿Cuál es la unidad de observación?**
* **¿Cuántas observaciones tiene la base?**
* **¿Cuántas variables tiene?** (solamente considerando las variables que ustedes consideren relevantes para el análisis, en caso de ser una base con muchas variables como WDI, EPH, EAH, ETOI)
* **¿Qué período de tiempo abarca**, si corresponde?
* Una breve descripción de la información que contiene la base.

La presentación debe permitir que una persona que no conoce previamente la base pueda comprender **qué información contiene y qué representa cada observación**.

---

## 2. Descripción de las variables

Realizar una descripción de las variables disponibles en la base.

Para cada variable deberán indicar:

| Variable   | Descripción      | Tipo de variable      | Valores nulos |
| ---------- | ---------------- | --------------------- | ------------: |
| Variable 1 | ¿Qué representa? | Numérica / categórica |            XX |
| Variable 2 | ¿Qué representa? | Numérica / categórica |            XX |
| ...        | ...              | ...                   |           ... |

Cuando sea relevante, indicar también los **principales valores o categorías** que toma cada variable.

El objetivo es conocer y describir la **estructura de la base de datos** antes de comenzar el análisis.

---

## 3. Exploración de los datos

Seleccionar algunas de las variables más relevantes de la base y realizar una primera exploración.

Se pueden utilizar, según corresponda:

* tablas de frecuencias;
* medidas de tendencia central;
* medidas de dispersión;
* histogramas;
* boxplots;
* gráficos de barras;
* gráficos de dispersión.

**No es necesario utilizar todos estos tipos de gráficos.** La elección debe estar relacionada con el tipo de variable y con aquello que se busca mostrar.

En esta primera entrega **no se espera que los gráficos tengan un diseño elaborado**. Se busca principalmente que sean correctos, legibles y adecuados para la información que se quiere mostrar.

La presentación y el diseño de las visualizaciones serán trabajados y mejorados durante las siguientes entregas.

---

## 4. Primeros hallazgos

A partir de la exploración realizada, identificar entre **3 y 5 hallazgos** que consideren relevantes.

Pueden referirse, por ejemplo, a:

* características de la distribución de una variable;
* diferencias entre grupos;
* relaciones entre variables;
* valores particularmente altos o bajos;
* presencia de valores nulos;
* posibles valores atípicos;
* patrones que resulten llamativos.

Los hallazgos deben estar acompañados por la información o gráfico que permita observarlos.

Además, indicar **una o dos preguntas** que hayan surgido a partir de esta primera exploración y que podrían ser analizadas en las próximas etapas del Trabajo Práctico.

---

## 5. Presentación

La entrega deberá realizarse **exclusivamente en formato PowerPoint (.pptx)**.

**Extensión sugerida: 8 a 12 diapositivas.**

La presentación debe tener una estructura clara y permitir seguir el análisis desde:

> **¿Qué datos tenemos? → ¿Cómo están estructurados? → ¿Qué encontramos al explorarlos? → ¿Qué preguntas surgen?**

En esta primera entrega se priorizará:

* claridad;
* orden;
* legibilidad;
* correcta utilización de tablas y gráficos;
* capacidad para comunicar los resultados.

**No se espera todavía un diseño avanzado de las visualizaciones.** El objetivo es comenzar a trabajar sobre la presentación de resultados y utilizar las siguientes entregas para mejorar progresivamente este aspecto.

---

## Evaluación

La **única entrega a evaluar será la presentación en PowerPoint**.

Se tendrán en cuenta:

* **Comprensión de la base:** identificación de la unidad de observación y características principales.
* **Descripción de las variables:** descripción, tipo de variable y valores nulos.
* **Análisis exploratorio:** correcta utilización de estadísticas, tablas y gráficos.
* **Interpretación:** capacidad para identificar y explicar primeros hallazgos.
* **Presentación:** claridad, orden y legibilidad de la información.
* **Coherencia:** existencia de un hilo conductor entre las distintas diapositivas.

Esta entrega constituye el **primer paso del Trabajo Práctico**. No se espera obtener conclusiones definitivas ni realizar análisis causales. El objetivo es conocer los datos, explorarlos y comenzar a formular preguntas que puedan ser desarrolladas en las siguientes etapas.
